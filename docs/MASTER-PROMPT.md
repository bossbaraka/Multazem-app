# 🕌 البرومبت المتكامل لبناء تطبيق «مُلتزم»

> **انسخ هذا البرومبت كاملاً والصقه في أداة بناء التطبيقات بالذكاء الاصطناعي (Arena Agent / Cursor / Lovable / FlutterFlow…)**
> كُتب بعناية ليكون مرجعاً شاملاً: الهوية، الميزات، الشاشات، التقنية، ومعايير القبول.

---

## 🎭 دورك كمنفّذ

أنت مطوّر تطبيقات خبير في **Flutter** ومصمم منتجات (Product Designer) محترف في تصميم التطبيقات العربية. مهمتك بناء تطبيق إسلامي متكامل اسمه **«مُلتزم»** — ليس مجرد تطبيق أذان، بل **رفيق يومي شامل ينظّم حياة المسلم كاملة**: صلاته، قرآنه، أذكاره، صيامه، وعباداته، مع نظام تذكير ذكي ومتابعة تحفيزية تساعده على الالتزام والاستمرارية.

التزم بكل التفاصيل أدناه، وعند التعارض بين أي عنصرين، الأولوية: **(1) صحة المحتوى الشرعي ← (2) الاعتمادية والعمل دون اتصال ← (3) جمال التجربة والهوية**. لا تبنِ واجهة جميلة على محتوى ناقص أو غير موثوق.

| العنصر | القيمة |

| **الشعار النصي (Tagline)** | «رفيقك اليومي نحو حياة ملتزمة» |
| **الفئة** | تطبيق إسلامي شامل — إدارة الروتين الديني اليومي |

| **الوضع الداكن** | مدعوم افتراضياً مع الليلي كخيار مفضّل |

## 2. الرؤية والفلسفة

- **التطبيق = روتين المسلم المتكامل**: من يستيقظ المستخدم على صوت الأذان حتى ينام على أذكار النوم، يكون «مُلتزم» حاضراً في كل لحظة.
- **لا تشتيت**: لا إعلانات، لا إشعارات استفزازية، لا محتوى فارغ. كل شاشة لها غاية عبادة أو تنظيم.
- **التدرّج لا الإحباط**: نظام تحفيزي رقيق يشجّع على الاستمرارية (قليلٌ دائم خيرٌ من كثيرٍ منقطع) دون جلد الذات.
- **الموثوقية الشرعية أولاً**: كل ذكر ودعاء وحديث يجب أن يُنسب لمصدره (صحيح البخاري، مسلم، حصن المسلم…)، وأي محتوى غير موثوق **يُمنع**.

## 3. الهوية البصرية (Design System)

### 3.1 الطابع العام
**كلاسيكي فاخر بزخارف إسلامية**: أقواس إسلامية (Moorish arches) في البطاقات والعناوين، زخارف هندسية إسلامية (Geometric Islamic Patterns) بشفافية خفيفة في الخلفيات، إطارات ذهبية رفيعة، تجربة تشبه «مصحف فاخر رقمي».

### 3.2 لوحة الألوان

| الاستخدام | اللون | الكود |
|---|---|---|
| اللون الأساسي | أخضر زمرّدي عميق | `#0B5D3B` |
| الأساسي الداكن | زمرّدي ليلي | `#083D28` |
| اللون المميّز (Accent) | ذهبي ملكي | `#C9A227` |
| الذهبي الفاتح | ذهبي حريري | `#E8C766` |
| خلفية فاتحة | عاجي ورقي | `#FAF6ED` |
| خلفية داكنة | ليلي مخضرّ | `#0D1B16` |
| نص أساسي | حبري داكن | `#1E2B26` (فاتح) / `#F0EDE4` (داكن) |
| نص ثانوي | رمادي دافئ | `#6B7A72` |
| نجاح/تقدّم | أخضر زمردي مشرق | `#1FA05E` |
| تحذير | كهرماني | `#D98E2B` |
| خطأ | عنابي هادئ | `#A63D40` |

### 3.3 الخطوط
- **نص المصحف**: خط «KFGQPC Uthmanic Script HAFS» أو «Amiri Quran» مع علامات الوقف والتشكيل الكامل.
- **عناوين الواجهة**: خط «Aref Ruqaa» أو «Amiri» (طابع تراثي فاخر).
- **نصوص الواجهة**: خط «Tajawal» أو «IBM Plex Sans Arabic» (وضوح عالٍ).

### 3.4 عناصر الواجهة
- بطاقات بأقواس إسلامية علوية، ظلال ناعمة، حواف 16–20px.
- أيقونات خطية (Line Icons) مخصصة بروح إسلامية، وليست أيقونات عامة.
- شاشة Splash: شعار «مُلتزم» داخل إطار مثمّن مزخرف مع متحرّك خفيف (نقش يتوهّج بالذهبي).
- حركات (Animations) هادئة ومريحة، 250–350ms، بدون مبالغة.
- كل الشاشات **RTL** بشكل أصلي، والأرقام عربية-مشرقية (٠١٢٣) كخيار في الإعدادات.

## 4. هيكل التطبيق والشاشات

### 4.1 شاشة البداية (Onboarding) — 5 خطوات فقط
1. ترحيب + آية افتتاحية بخط جميل.
2. تحديد الموقع (تلقائي GPS أو يدوي بالمدينة).
3. طريقة حساب المواقيت (أم القرى / رابطة العالم الإسلامي / هيئة المساحة المصرية / أمريكا الشمالية… إلخ) + المذهب في حساب العصر (جمهور/حنفي).
4. اختيار صوت المؤذن المفضّل (٥ خيارات: الحرم المكي، ناصر القطامي، مشاري العفاسي، علي أحمد ملا…).
5. اختيار ما يريد التطبيق تذكيره به (قائمة بمربعات اختيار) — لا إجبار.

### 4.2 الرئيسية — «يومي» (الشاشة المحورية)
لوحة تحكم يومية تعرض بترتيب زمني حي:
- **التقويم المزدوج** أعلى الشاشة: التاريخ الهجري بارزاً + الميلادي بجانبه.
- **بطاقة الصلاة القادمة**: اسمها، وقتها، عدّاد تنازلي حي (حجم كبير)، وشريط تقدّم اليوم (كم صلاة أتممت).
- **خطة اليوم (Routine Cards)**: بطاقات موقوتة تظهر في وقتها تلقائياً:
  - قبيل الفجر: «قيام الليل والوتر»
  - بعد الفجر: «أذكار الصباح» + «وردك القرآني اليومي»
  - الظهر–العصر: «ورد القرآن» متابعة
  - بعد العصر/المغرب: «أذكار المساء»
  - يوم الجمعة: بطاقة خاصة «سورة الكهف + الصلاة على النبي ﷺ» مع عدّاد
  - الاثنين والخميس: بطاقة «صيام التطوّع» مع زر «نية الصيام»
  - قبل النوم: «أذكار النوم + آية الكرسي»
- كل بطاقة قابلة للإنجاز (✓) فتُسجَّل في سجلّ الالتزام.
- إنجاز اليوم كله = رسالة تحفيزية + أثر بصري (إطار ذهبي حول اليوم في التقويم).

### 4.3 تبويب الصلاة 🕌
- جدول المواقيت الخمسة + الشروق + الإمساكية اليومية والأسبوعية.
- اتجاه **القبلة** (بوصلة حية باهتزاز بسيط عند الاتجاه الصحيح).
- **سجلّ الصلوات**: تسجيل كل صلاة (في وقتها / قضاءً / جماعة) — رسم أسبوعي وشهري.
- صفحة خاصة بكل صلاة: سننها، أذكار بعدها، أحاديث فضلها.
- وضع «خشوع» اختياري: كتم الإشعارات غير الضرورية وقت الصلاة.

### 4.4 تبويب القرآن الكريم 📖
- **مصحف كامل** بتلاوة ورسم صفحات المصحف (تخطيط صفحة حقيقية 604 صفحات)، دعم التصفح بالسورة/الجزء/الصفحة.
- **أوضاع قراءة**: وضع ليلي، وضع «تدبّر» (إخفاء كل شيء إلا النص).
- **تلاوات صوتية** لكل آية/سورة (٥ قرّاء على الأقل) مع إمكانية التحميل للاستماع دون اتصال، وتكرار الآية للحفظ.
- **التفسير الميسّر** لكل آية (مع إمكانية تبديل المصدر).
- **الحفظ والمراجعة**: إنشاء خطة حفظ (السور المطلوبة + الموعد) ⇐ التطبيق يقسّمها ورداً يومياً ويذكّر بها + اختبار مراجعة (إخفاء الآية والتسميع النصي).
- **بحث** في النص القرآني، **علامات مرجعية**، «آخر قراءة» تلقائي، و**ورد يومي** (الختمة: شهر/٣ أشهر/٦ أشهر ⇐ جدولة تلقائية).
- إحصائيات: صفحات/أجزاء مكتملة، سلسلة الأيام (Streak).

### 4.5 تبويب الأذكار والأدعية 🤲
- **حصن المسلم** كاملاً ومصنّفاً: الصباح، المساء، بعد الصلاة، النوم، الاستيقاظ، دخول/الخروج، السفر، الرقية… إلخ.
- كل ذكر: النص بالتشكيل + العدد المطلوب + **عدّاد لمس** + المصدر (البخاري/مسلم…) + فضله عند توفّره.
- **السبحة الرقمية**: عدّاد كبير مريح باهتزاز خفيف، أهداف (٣٣/١٠٠/٥٠٠)، سبح مخصصة، سجلّ تراكمي.
- **مكتبة الأدعية**: من القرآن والسنة مصنّفة حسب المناسبات مع زرّي نسخ ومشاركة ببطاقة مزخرفة.
- **أسماء الله الحسنى** (٩٩) صفحة بصفحة مع المعنى المختصر.

### 4.6 التقويم الهجري والمناسبات 📅
- تقويم هجري كامل قابل للتحويل (هجري ⇐ ميلادي).
- إبراز: رمضان والعشر الأواخر، العيدان، عرفة، عاشوراء، الأيام البيض (١٣–١٤–١٥)، الإسراء والمعراج، رجب وشعبان، ذو الحجة…
- بطاقة لكل مناسبة: فضلها وما يُستحبّ فيها.

### 4.7 الصيام 🌙
- متتبّع الصيام: تطوّع (اثنين/خميس، بيض، عاشوراء، عرفة، شوال) + رمضان كاملاً (سجلّ القضاء لمن لزمها).
- رمضان: إمساكية شهرية قابلة للمشاركة كصورة مزخرفة، عدّاد أيام، مهام العشر الأواخر، تذكير قيام الليل.
- عدّاد صدقة يومية اختياري.

### 4.8 المكتبة الإسلامية 📚
- أركان الإسلام والإيمان، **الأربعون النووية** (مع شرح مختصر)، مختصر السيرة النبوية، قصص الأنبياء، أحكام ميسّرة (الطهارة والصلاة والزكاة خطوة بخطوة برسوم توضيحية).
- كل محتوى **بمصادر موثوقة** فقط، ويُعرض ببطاقات قراءة مريحة (وضع قراءة كتب).

### 4.9 الملف والإنجازات 👤
- إحصائيات شاملة: نسبة الالتزام بالصلوات، أيام متتالية (Streaks) للقرآن والأذكار، أجزاء مقروءة، تسبيحات تراكمية.
- **أوسمة (Badges)** بأسماء روحانية: «المواظب»، «قارئ الكهف»، «صائم الخميس»، «خادم الورد»…
- تقرير أسبوعي لطيف: «أسبوعك مع مُلتزم».
- مشاركة الإنجازات كبطاقات مزخرفة (اختياري — بلا ضغط اجتماعي).

### 4.10 الإعدادات ⚙️
الحسابات والمواقيت، الأذان (الصوت/المدة/لكل صلاة على حدة: صامت/تنبيه/أذان كامل/تكبيرات الأذان فقط)، الإشعارات كل نوع بمفتاح مستقل، اللغة، الثيم (فاتح/داكن/تلقائي)، حجم خط المصحف، النسخ الاحتياطي السحابي أو المحلي، إعادة ضبط.

### 4.11 تبويب العطاء والصدقة 💚

- **سجلّ صدقاتي (سريّ ١٠٠٪ ومحلي)**: تسجيل صدقة (مبلغ/نوع: مال، طعام، وقت، عينية…) مع خيار **«أخفِها»** — وضع الإخفاء يُظهر ☆ بدل الأرقام، استناداً لقوله تعالى: ﴿وَإِن تُخْفُوهَا وَتُؤْتُوهَا الْفُقَرَاءَ فَهُوَ خَيْرٌ لَّكُمْ﴾. البيانات على الجهاز فقط ولا تُزامَن أبداً.
- **جهات رسمية موثوقة**: دليل منصات تبرع حكومية/معتمدة مصنّفة (صدقة عامة، زكاة، كفالة يتيم، وقف/صدقة جارية، إغاثة عاجلة) وقابلة للفلترة حسب البلد — **الفتح عبر رابط خارجي (`url_launcher`) للموقع الرسمي فقط**، مع إخلاء مسؤولية دائم الظهور: «التبرع يتم عبر المواقع الرسمية للجهات، ولا يجمع التطبيق أي أموال أو عمولات».
- **صدقة جارية**: أفكار مشاريع (حفر بئر، طباعة مصاحف، كفالة يتيم، سقيا الماء) + تذكير دوري اختياري.
- **إحصاء العطاء**: مجموع الشهر، سلسلة «أيام العطاء»، وهدف صدقة يومية اختياري — بعرض محفّز لا مُلوم.
- **شرط قانوني إلزامي**: لا معالجة مدفوعات داخل التطبيق إطلاقاً ولا IAP للتبرعات (امتثال صارم لسياسات App Store ‏3.2.2 وGoogle Play) — كل التبرعات خارجية عبر المواقع الرسمية للجهات فقط.

## 5. نظام التذكيرات الذكي (Notifications Engine)

نظام محلي بالكامل (بدون خادم)، مجدول وذكي:
- **الأذان**: إشعار بصوت الأذان الكامل المختار عند دخول الوقت (مع حالات Android/iOS الخاصة بالأصوات الطويلة — استخدم قنوات الإشعارات بأصوات مخصصة مدمجة في التطبيق).
- **تنبيه ما قبل الصلاة** (١٠ دقائق اختيارياً): «اقترب وقت…».
- **أذكار الصباح** (بعد الفجر بـ١٠ د) و**المساء** (بعد العصر) — قابلة للتخصيص.
- **أذكار النوم** بوقت يحدده المستخدم.
- **الكهف يوم الجمعة** + أذكار الجمعة.
- **صيام الاثنين والخميس والأيام البيض** (اختياري).
- **ورد القرآن اليومي** و**الحفظ** حسب الخطة.
- لفتات لطيفة دورية (دعاء/حديث/آية مع المصدر) — بحد أقصى ١–٢ يومياً ومفتاح إيقاف واضح.
- **تذكير صدقة يوم الجمعة صباحاً** (خير يوم طلعت عليه الشمس) و**صدقة يومية** اختيارية بوقت يحدّده المستخدم.
- حكم ذهبي: **لا إشعار بلا فائدة عبادة**.

## 6. البيانات والمصادر (APIs & Data)

| الوظيفة | المصدر |
|---|---|
| مواقيت الصلاة | حساب محلي Offline عبر حزمة `adhan` (أفضل الأداء) مع تزامن اختياري مع **Aladhan API** (`aladhan.com/prayer-times-api`) |
| نص المصحف والترجمات والتفسير | **AlQuran Cloud API** / **Quran.com API v4** — وتُخزَّن محلياً بالكامل داخل التطبيق (SQLite) ليعمل بلا إنترنت |
| التلاوات الصوتية | **mp3quran.net API** / EveryAyah — بثّ + تحميل اختياري |
| التقويم الهجري | محلي بالكامل (حزم `hijri` / `Intl islamic-umalqura`) |
| الأذكار | حصن المسلم (JSON مفتوح المصدر) مدمج محلياً مع نسبة كل ذكر لمصدره |

> **قاعدة إلزامية**: كل المحتوى الشرعي (مصحف، تفسير، أذكار، أحاديث) يُشحن **مدمجاً محلياً** في التطبيق؛ الإنترنت فقط للبثّ الصوتي والمزامنة الاختيارية.

## 7. المتطلبات التقنية

- **Flutter (Dart) آخر نسخة مستقرة**، معمارية نظيفة مقترحة: `Riverpod` أو `Bloc` + مجلدات `features/`.
- تخزين محلي: `drift` أو `sqflite` للبيانات، `Hive`/`shared_preferences` للإعدادات.
- إشعارات: `flutter_local_notifications` + `timezone` (جدولة دورية دقيقة، والتعامل مع الأذان عبر قنوات بأصوات مخصصة).
- صوتيات: `just_audio` مع تحكم بلّوح (Notification/Media Controls) وتشغيل بالخلفية.
- موقع: `geolocator` + اختيار يدوي للمدينة، وبوصلة: `flutter_compass`/`sensors`.
- أداء: إقلاع أقل من ثانيتين، لا تحميل زائد، دعم الأجهزة الضعيفة، واستهلاك بطارية منخفض.
- يعمل **Offline-first** ١٠٠٪ عدا بثّ التلاوات.
- الوصولية (Accessibility): تباين ألوان AA، دعم TalkBack/VoiceOver، أحجام خط قابلة للتكبير.
- الخصوصية: لا حسابات إجبارية، الموقع يبقى على الجهاز، لا تتبّع، بيانات المستخدم ملكه (تصدير/استيراد).
- تغطية اختبار للمنطق الحرج: حساب المواقيت، الجدولة، العدّادات.

## 8. خطة التنفيذ على مراحل

**المرحلة ٠ — الأساس**: الهوية والثيم (فاتح/داكن)، التنقّل RTL بالتبويبات، شاشة البداية، هيكل البيانات المحلي.

**المرحلة ١ (MVP الأساسي)**: المواقيت + أصوات الأذان والإشعارات + القبلة ⇢ الرئيسية «يومي» ⇢ سجلّ الصلوات.

**المرحلة ٢ — القرآن**: المصحف الكامل محلياً + القراءة + التلاوات + العلامات + آخر قراءة + البحث.

**المرحلة ٣ — الأذكار والأدعية**: حصن المسلم كاملاً + السبحة + مكتبة الأدعية + أسماء الله الحسنى.

**المرحلة ٤ — التنظيم والتحفيز**: خطة الختمة والحفظ، التقويم الهجري والمناسبات، متتبّع الصيام، **تبويب العطاء والصدقة**، الإنجازات والتقرير الأسبوعي.

**المرحلة ٥ — الصقل**: المكتبة الإسلامية، النسخ الاحتياطي، الوصولية، تحسين الأداء، وثائق التشغيل والنشر (ملف `README` + خطوات بناء APK/AAB وIPA).

نفّذ المراحل **بالتسلسل**، وبعد كل مرحلة: اختبرها، اعرض ملخص ما أُنجز، ثم انتقل للتي تليها.

## 9. معايير القبول (Acceptance Criteria)

✅ كل المواقيت تُحسب محلياً بدقة لأي مدينة، وتعمل بدون إنترنت.
✅ إشعار الأذان يعمل بصوت مؤذن كامل حسب اختيار المستخدم لكل صلاة.
✅ المصحف بسلاسة ٦٠ إطاراً، خط عثماني واضح، مع تفسير وحفظ مكان القراءة.
✅ كل ذكر/حديث **مصنّف بمصدره** — ويُمنع أي محتوى بلا مصدر.
✅ RTL مثالي في كل الشاشات والثيم داكن/فاتح بلا عيوب.
✅ الهوية مطبّقة بدقة: الزمردي/الذهبي والأقواس والزخارف في كل بطاقة.
✅ التطبيق مكتمل الميزات المذكورة ولا يحتوي شاشات «قريباً» وهمية ضعيفة.
✅ تبويب العطاء يوجّه لجهات رسمية عبر روابط خارجية فقط (بدون جمع أموال داخل التطبيق)، مع وضع إخفاء الصدقة وإخلاء المسؤولية.

## 10. تعليمات نهائية للمنفّذ

1. ابدأ بهيكل المشروع (Project Structure) كاملاً ثم نفّذ مرحلة مرحلة حسب القسم ٨.
2. اكتب كوداً نظيفاً موثّقاً بالعربية/الإنجليزية، قابلاً للصيانة.
3. عند أي غموض اتخذ القرار الأكثر احتراماً لوقت المستخدم وعقيدته، واذكر قرارك في الملخص.
4. الهدف النهائي: تطبيق يفخر به متدرّب Flutter محترف ويستشعر فيه المستخدم سكون المسجد وهيبة المصحف.
