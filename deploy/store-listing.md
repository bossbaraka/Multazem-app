# بطاقة المتجر — نص جاهز للنشر (Google Play + App Store)

## الاسم القصير
```
مُلتزم — روتين المسلم اليومي
```

## العنوان الكامل
```
مُلتزم: صلاة، قرآن، أذكار، ختمة، صيام، عطاء — بدون إعلانات
```

## الوصف القصير (٨٠ حرفاً)
```
رفيقك اليومي نحو حياة ملتزمة: الأذان والقرآن والأذكار والختمة والعطاء — مجاني بلا إعلانات ولا حسابات 🤍
```

## الوصف الكامل (النسخة العربية — انسخه كما هو)
```
🕌 مُلتزم — تطبيق إسلامي شامل ينظّم يوم المسلم من الأذان حتى أذكار النوم

هل تبحث عن تطبيق يساعدك على الالتزام اليومي بلا إعلانات تشتتك وبلا إشعارات فارغة؟ «مُلتزم» هو رفيقك: مواقيت دقيقة، قرآن بتلاوة وتفسير، أذكار موثوقة بمصادرها، خطة ختمة، سبحة، تقويم هجري، صدقة، وتتبّع أخلاق — كل ذلك مجاناً ١٠٠٪ وصدقة جارية.

✨ لماذا «مُلتزم» مختلف؟
• 🚫 بلا إعلانات إطلاقاً وبلا حسابات إجبارية
• 📴 يعمل بدون إنترنت (Offline-First) — مواقيتك وقرآنك وأذكارك تبقى على جهازك
• 🔍 كل ذكر وحديث بمصدره ورقمه (البخاري، مسلم، حصن المسلم)
• 💚 قسم عطاء خاص يربطك بجهات رسمية خارجية فقط — دون جمع أموال

🕌 الصلاة
• مواقيت دقيقة محسوبة محلياً (أم القرى، الرابطة، الهيئة المصرية، إسنا…)
• إشعار أذان لكل صلاة بمفتاح مستقل (كامل / صامت / إيقاف) وبصوت مؤذنك المفضل
• اتجاه القبلة + سجل صلوات (في وقتها / جماعة / قضاء) مع رسم أسبوعي

📖 القرآن الكريم
• مصحف كامل بالرسم العثماني مع تلاوة لكل سورة والآية
• التفسير الميسر بضغطة واحدة على الآية
• خطتي للختمة: ٣٠/٩٠/١٨٠ يوم من ٦٠٤ صفحات مع ورد يومي وتذكير
• تعلّم التلاوة بالتلقين: اسمع وكرِّر الآية بصوت القارئ كرّة بعد كرّة

🎓 علِّمني القرآن
• ١٢ درس تجويد في ٣ مستويات (نون ساكنة، ميم، مدود، قلقلة، مخارج)
• اختبر نفسك: ١٢ سؤالاً ونتيجة محفوظة
• مخارج الحروف تفصيلياً (لسان، حلق، جوف، شفة، خيشوم)

🤲 الأذكار
• حصن المسلم كاملاً: الصباح، المساء، بعد الصلاة، النوم، السفر، الرقية
• سبحة رقمية بأهداف ٣٣/١٠٠/٥٠٠ مع اهتزاز وإجمالي تراكمي
• مكتبة أدعية مصنّفة بنسخ ومشاركة

🗓️ التقويم الهجري والصيام
• شهر هجري كامل مع المناسبات بمصادرها (عاشوراء، البيض، شوال، عرفة)
• متتبع صيام: تطوع/قضاء/رمضان مع سلسلة وعدّاد الشهر
• تذكير صيام الاثنين والخميس والأيام البيض

✨ علِّمني الأخلاق
• ١٥ خلقاً كريماً بشرح مفصّل ودليله وتطبيقه اليومي (صدق، أمانة، بر الوالدين، عفو…)
• مؤشر التزام أسبوعي: تقييم ذاتي مع تحليل قوة/ضعف وشارت تقدّم

💚 العطاء والصدقة
• سجل صدقات سري مع وضع «إخفاء» يُخفي المبالغ
• دليل جهات رسمية موثوقة (روابط مباشرة خارجية — لا نجمع أموالاً)
• أفكار صدقة جارية

🏆 الإنجازات
• ٨ أوسمة تُفتح بالالتزام الفعلي: المواظب، حارس الفجر، سيد الذكر…
• ملخص أسبوعي ملهم دون ضغط

📚 المكتبة
• الأربعون النووية بأحاديثها ومعانيها
• خط زمني للسيرة + صفة الوضوء والصلاة
• أسماء الله الحسنى الـ ٩٩

🎨 الهوية
• زمردي ملكي وذهبي مع زخارف إسلامية فاخرة
• عربي بالكامل RTL مع وضع داكن ليلي
• خط مصحف عثماني بأحجام قابلة للتكبير

التطبيق في تطور مستمر بإذن الله — صدقة جارية نقبل بها دعاءكم ومقترحاتكم.
لاحظ: `keyAlias` وملف التوقيع في نسختك المحلية.
```

## بيانات إدارة المتجر (Google Play Console)
| الحقل | القيمة المقترحة |
|---|---|
| الفئة | التعليم / الدين والروحانية (Lifestyle → اللياقة الروحية إن وجدت) |
| المحتوى المناسب | للجميع (PEGI 3 / Everyone) |
| الإعلانات | لا يحتوي على إعلانات |
| البيانات الشخصية | لا يجمع ولا يشارك بيانات (نموذج Data Safety مملوء) |
| استهداف الجماهير | ٣+ — عام |
| جدولة التحديثات | شهري — مع مواسم (رمضان، عيد الأضحى، رجب) |
| رابط الخصوصية | رابط صفحة `privacy-policy.md` على GitHub Pages أو موقعك |
| رابط الموقع الإلكتروني | أضِف رابطاً بسيطاً — يُقلّل احتمال رفض مراجعة Play |

## نص الرد على مراجعة App Store الروتينية (إن طُلب)
```
إخوتنا الكرام في مراجعة App Store: تطبيق «مُلتزم» تطبيق ديني تعليمي مجاني بالكامل، لا إعلانات، لا حسابات. كل البيانات (موقيت صلاة، تفضيلات، سجلات) تُخزن محلياً على جهاز المستخدم فقط. قسم «العطاء» يفتح روابط خارجية رسمية للجهات الخيرية — التطبيق لا يجمع أي مبالغ ولا يعالج أي مدفوعات داخلية (متوافق تماماً مع App Store Review Guidelines 3.2.2 — charitable donations via external official links only).
```

## لقطات مقترحة للمتجر (٨ — بهوية التطبيق)
1. الرئيسية (يومي) مع بطاقة الصلاة القادمة والعدّاد
2. مواقيت اليوم بالألوان الزمرّدية
3. مصحف بخط عثماني (سورة الكهف)
4. شاشة علِّمني القرآن (درس الإظهار)
5. السبحة الرقمية بحلقة التقدم
6. مؤشر الأخلاق (الدائرة الذهبية)
7. التقويم الهجري بعلامات المناسبات
8. تبويب العطاء (إخلاء المسؤولية + الجهات)
