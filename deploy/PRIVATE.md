# 📱 تشغيل «مُلتزم» بشكل خاص — بدون متاجر على الإطلاق

> تريد التطبيق على هاتفك أنت فقط (أو أهلك وأصحابك عبر ملف)، بلا حسابات مطوّرين ولا لوائح متجر. هذا الدليل هو المسار الوحيد الذي تحتاجه.
>
> **النبأ السار:** الاستخدام الخاص لا يحتاج مفتاح توقيع، ولا سياسة خصوصية منشورة، ولا وصف متجر. (كلها جاهزة في `deploy/` إن غيّرت رأيك يوماً.)

---

## 🤖 أندرويد — أسهل مسار (١٠ دقائق)

### الطريقة ١: البناء على جهازك (Windows / Mac / Linux)

```bash
# ثبّت Flutter مرة واحدة: https://docs.flutter.dev/get-started/install
cd multazim

# ١) أنشئ مجلدات المنصة الرسمية (مرة واحدة فقط)
flutter create . --org com.multazim.app --platforms=android

# ٢) انسخ ملفَّي النشر (المانيفست + الأيقونات)
# — على Windows استخدم نسخ/لصق من مستكشف الملفات إن رغبت —
cp deploy/android/app/src/main/AndroidManifest.xml android/app/src/main/
cp -r deploy/icons/android/res/* android/app/src/main/res/

# ٣) بِلّغ المطلوبات وابنِ
flutter pub get
flutter build apk --release --split-per-abi
```

ثم:
1. خذ الملف: `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk` (هذا المطلوب لـ ٩٩٪ من الهواتف الحديثة. إن فشل التثبيت جرّب `app-release.apk` الموحّد من نفس المجلد).
2. أرسله لهاتفك (واتساب لنفسك / كيبل USB / Google Drive).
3. افتحه من الهاتف ⟶ سيسألك *«السماح بالتثبيت من مصادر غير معروفة»* ⟶ اسمح ⟶ **مُثبَّت** ✅

> **لا مفتاح توقيع مطلوب** — إعدادات `deploy/android/app/build.gradle.kts.additions` تستخدم التوقيع التلقائي عند غياب `key.properties`، وهو مثالي للاستخدام الشخصي. **المهم:** كل تثبيت بعده يجب أن يُبنى على نفس الجهاز/التوقيع حتى يُحدَّث التطبيق سليماً مع بقاء بياناتك.

### الطريقة ٢: لا تريد تثبيت Flutter أصلاً؟ البناء السحابي المجاني

1. أنشئ حساب GitHub (مجاني) وارفع مجلد `multazim` كمستودع **خاص**.
2. ادخل https://codemagic.io ⟶ سجّل بحساب GitHub ⟶ «Add application» ⟶ اختر المستودع.
3. كودماجِك سيلتقط ملف `codemagic.yaml` الموجود في جذر المشروع ⟶ اضغط **Start build** لسير العمل `android-apk`.
4. بعد ~١٠ دقائق: نزّل **APK** من صفحة النتائج (Artifacts) ⟶ أرسله لهاتفك ⟶ تم.

> الخطة المجانية تكفي تماماً (عدة بناءات شهرياً). والملف نفسه يبني لك نسخة iOS بالأسفل.

## 🍎 iOS — خياران حسب ما تملك

> الآيفون لا يسمح بتثبيت ملفات «بضغطة» كأندرويد. أمامك طريقان مجانية بالكامل:

### الخيار أ) تملك Mac (الأسهل — مجاني مدى الحياة)

```bash
cd multazim
flutter create . --org com.multazim.app --platforms=ios
flutter pub get
open ios/Runner.xcworkspace
```
ثم داخل Xcode:
1. اختر **Runner** ⟶ **Signing & Capabilities** ⟶ فعّل *Automatically manage signing* ⟶ اختر حساب Apple ID المجاني الخاص بك (Add Account).
2. صِل الآيفون بكيبل ⟶ اختر جهازك من الأعلى ⟶ اضغط ▶️ **Run**.
3. على الآيفون: الإعدادات ⟶ عام ⟶ VPN وإدارة الجهاز ⟶ وثّق بمطوّرك.

**التنبيه الوحيد:** الشهادة المجانية تدوم **٧ أيام** ثم يتوقف التطبيق عن الفتح؛ اضغط Run مجدداً (٢٠ ثانية) ليعود — بياناتك لا تتأثر. كثيرون يستخدمون هكذا لسنوات.

### الخيار ب) لا تملك Mac — Codemagic + SideStore (مجاني تماماً)

هذا التركيب يحاكي امتلاك Mac سحابياً + «متجر خاص» لهاتفك:

**مرة واحدة — تجهيز SideStore على الآيفون (١٥ دقيقة):**
1. من أي كمبيوتر (Windows/Mac/Linux) ثبّت **SideServer** + **iTunes** (من موقع Apple، ليس Microsoft Store) + **iCloud**.
2. اتبع دليل التثبيت الرسمي: https://sidestore.io ⟶ سيتم تثبيت تطبيق SideStore على الآيفون بحساب Apple ID مجاني.
3. SideStore يجدّد شهادة تطبيقاتك **تلقائياً عبر Wi-Fi** كل ٧ أيام — لن تلمس الكمبيوتر ثانية.

**كل تحديث — بناء IPA سحابياً (٥ دقائق تفاعل):**
1. كما في أندرويد: ارفع المشروع لـ Codemagic.
2. شغّل سير العمل `ios-ipa` ⟵ من `codemagic.yaml` في جذر المشروع ⟶ سينتج **IPA بدون توقيع** مجاناً على أجهزة Mac حقيقية.
3. حمّل ملف IPA إلى الآيفون (AirDrop غير متاح؟ انقله عبر iCloud Drive/كيبل ⟶ Files).
4. افتح **SideStore** ⟶ **+** ⟶ اختر ملف IPA ⟶ سيُوقّع ويُثبَّت «مُلتزم» على شاشتك الرئيسية ✅

> الشهادة المجانية تحدّها قيود Apple: حتى **٣ تطبيقات** مُثبَّتة بهذه الطريقة (يكفيك ١). وأي تطبيق يحتاج تجديداً أسبوعياً تلقائياً — SideStore يديره صامتاً.

### وماذا عن حساب المطوّرين المدفوع (Apple Developer ‏$99/سنة)؟
يمنحك سنة كاملة دون تجديد + توزيع لـ ١٠٠ جهاز عبر TestFlight — **لكنه غير مطلوب إطلاقاً** للاستخدام الخاص. ابدأ مجاناً؛ إن ضاقت عليك الـ ٧ أيام لاحقاً فكّر به.

## 🔁 التحديثات (+ حماية بياناتك)

بيانات «مُلتزم» كلها **محلية داخل التطبيق** (سجلات، صدقة، ختمة، أذكار…). الحذف = الفقد. لذلك:

1. **قبل أي تحديث أو اليأس إن توقف:** التطبيق ⟶ الإعدادات ⟶ **نسخ احتياطي** ⟶ صدّر JSON وأبقِه عندك.
2. **للتحديث:** ابنِ بنفس الطريقة (نفس التوقيع) وثبّت «فوق» القديم — سيحافظ على كل شيء.
3. إن كان التوقيع اختلف (جهاز آخر مثلاً): احذف القديم ⟶ ثبّت الجديد ⟶ استعد من الـ JSON.

> 💡 لتقارب كل الأجهزة على رقم إصدار: قبل كل بناء زيد الرقم في `pubspec.yaml`: `version: 1.0.1+2` (الأخير زيادة في كل بناء).

## ⚡ نصيحة واحدة مهمة للإحثّان (Athân) والتذكيرات

حتى يعمل الأذان والتذكيرات في الخلفية بشكل ثابت بعد تثبيت خاص:
- **أندرويد:** إعدادات الهاتف ⟶ التطبيقات ⟶ مُلتزم ⟶ البطارية ⟶ **غير مقيَّد / لا تحسين**. وفعّل «الإشعارات».
- **iOS:** فعّل الإشعارات من المرة الأولى، ولا تُنهِ التطبيق من المبدِّل (swipe-up kill يوقف التنبيهات حتى إعادة فتحه — قيود نظام Apple).
