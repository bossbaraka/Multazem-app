# 🕌 مُلتزم (Multazim)

> رفيقك اليومي نحو حياة ملتزمة — تطبيق إسلامي متكامل: مواقيت، قرآن، أذكار، صيام، عطاء، وتنظيم يوم المسلم.
> Flutter (Android + iOS) · RTL · Offline-first · 💚 مجاني ١٠٠٪ بدون إعلانات.

## ⚡ التشغيل السريع (خطوتان)

الهيكل هنا يحوي `lib/` و`pubspec.yaml` كاملين. لتوليد مجلدات المنصات (`android/`, `ios/`):

```bash
cd multazim
flutter create . --org com.multazim.app --platforms=android,ios
flutter pub get
# إلزامي لأندرويد: تفعيل Core Library Desugaring الذي يتطلبه
# flutter_local_notifications (يُطبَّق تلقائياً على Codemagic)
python3 deploy/android/apply_android_gradle.py
flutter run
```

**أو بأمر واحد** (يولّد المنصات + المانيفست + الأيقونات + desugaring + مفاتيح iOS):

```bash
bash scripts/setup_platforms.sh          # macOS / Linux
powershell -ExecutionPolicy Bypass -File scripts\setup_platforms.ps1   # Windows
```

> 🤖 **تبني باستخدام Google Antigravity؟** اتبع الدليل الكامل: [**`docs/ANTIGRAVITY.md`**](docs/ANTIGRAVITY.md)
> (التثبيت، إعداد المشروع والوكيل، خطة المهام الجاهزة للصق، واستكشاف الأخطاء).
> وقواعد العمل للوكيل في [**`AGENTS.md`**](AGENTS.md).

> المتطلّب: Flutter 3.24+ (تحقّق: `flutter --version`)
>
> ⚠️ لا تُضف حزمة `vibration` القديمة: نسخة 1.x تعتمد v1 embedding المزال فتُفشل بناء أندرويد. الاهتزاز هنا عبر `HapticFeedback` المدمجة.

## 🗂️ البنية

```
lib/
├── main.dart                 # نقطة الدخول (تهيئة الإشعارات/التخزين)
├── app.dart                  # MaterialApp + RTL + الثيمات
├── core/
│   ├── theme/                # الهوية: زمردي/ذهبي + خطوط (طجوال/أميري)
│   ├── routing/              # go_router + الشريط السفلي (٥ تبويبات)
│   ├── widgets/              # OrnamentedCard + زخارف إسلامية مشتركة
│   ├── providers/            # مواقيت الصلاة (adhan) + التاريخ الهجري
│   └── services/             # NotificationService (أذان/تذكيرات)
└── features/
    ├── onboarding/           # ٥ خطوات: الموقع، الحساب، المؤذن، التذكيرات
    ├── home/                 # «يومي»: الصلاة القادمة + عدّاد + بطاقات الروتين
    ├── prayer/               # المواقيت + سجل الصلوات + القبلة
    ├── quran/                # فهرس السور (١١٤) — المصحف الكامل في المرحلة ٢
    ├── adhkar/               # حصن المسلم (بذور مصنّفة بمصادرها) + عدّاد لمس
    ├── giving/               # 💚 العطاء: سجل صدقات سري + جهات رسمية خارجية
    └── settings/             # الثيم، الأذان، الإشعارات، الخط، الخصوصية
```

## 🔊 أصول مطلوبة (تُضاف قبل الإصدار)

| المسار | المحتوى |
|---|---|
| `assets/sounds/` | `adhan_makkah.mp3`, `adhan_qatami.mp3`, `adhan_afasy.mp3`, `adhan_madani.mp3`, `adhkar_ping.mp3` |
| `assets/fonts/` | `AmiriQuran-Regular.ttf` (نص المصحف) — خط أميري قرآن الرسمي |
| `assets/data/` | `charities.json` ✅ (موجود) · `adhkar_full.json` (حصن المسلم كاملاً — المرحلة ٣) · قاعدة المصحف SQLite (المرحلة ٢) |

> **الأذان على أندرويد/iOS**: يجب نسخ ملفات الصوت أيضاً إلى `android/app/src/main/res/raw/` وحزمة iOS لتعمل مع قنوات الإشعارات (انظر `notification_service.dart`).
> **الشبكة (android release)**: أضف `<uses-permission android:name="android.permission.INTERNET"/>` في `android/app/src/main/AndroidManifest.xml` (للتلاوة وجلب نص المصحف أول مرة)، وفعّل `SCHEDULE_EXACT_ALARM` للأذان الدقيق.

## 💚 سياسة قسم العطاء (إلزامية)

- التطبيق **لا يجمع أي أموال ولا يعالج مدفوعات** — كل التبرعات عبر روابط خارجية للمواقع الرسمية للجهات فقط (امتثال App Store 3.2.2 و Google Play).
- `assets/data/charities.json` قائمة **قابلة للتحديث**: راجع رسمية كل جهة قبل النشر، وأضف/احذف حسب البلد.
- سجلّ الصدقات محلي ١٠٠٪ ولا يُزامَن — وضع «أخفِها» يُخفي المبالغ (☆).
